The build you meant to try.

See versions, build numbers, notes, and download progress in one place. Recent builds come first, with older builds available when you need them.

Downloaded means the transfer finished. iOS controls installation, and Deploy Link cannot confirm its completion. Open the app you installed to check it.

You host the queue.

The Mac stores and serves your builds. The iOS app connects to the HTTPS address you provide. Tailscale controls which devices can reach it; an optional management token allows queue deletion.

Both the viewer and server are open source under Apache 2.0. Tailscale is separate, with its own plans and terms.

Start with your Mac.

The Python server is installed from the source repository. It also provides a browser page you can open in Safari on your device.
