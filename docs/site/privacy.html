Your queue and its records.

Deploy Link does not operate a build-hosting service or receive your queue on a developer-operated server. The app connects to the server address you choose.

Effective October 30, 2026. Developer: Alex Morris.

On the iPhone or iPad

The app stores your server address and a randomly generated device identifier locally. It sends that identifier and the device family, such as iPhone or iPad, to your server to match downloads with this device. This is an app-generated identifier, not the device’s advertising identifier or Apple provisioning UDID.

If you add a management token, it is stored locally and sent to your selected server to authorize queue deletion. Do not connect to a server you do not trust. Ordinary listing and downloads use your network’s access rules; the management token does not make a publicly exposed queue private.

On your Mac server

The queue contains signed application packages, app icons, bundle identifiers, versions, build numbers, release notes, and provisioning-profile summaries. The original signed package may itself contain provisioning details such as registered device identifiers.

Download records contain transfer timestamps, byte counts, completion status, device family, the app-generated device identifier when provided, and the request’s user-agent string. The server also records ordinary request diagnostics in its local log. A separate device-history file remembers the latest completed download of each app even after that release leaves the queue.

These records are available to the person administering your server and, where exposed by the queue API, other devices allowed to reach it. There is no separate per-user permission system for browsing. Configure Tailscale access accordingly.

Services and transport

The iOS app uses HTTPS to access your server. The recommended configuration uses Tailscale Serve, which may carry encrypted network traffic directly or through a relay. Tailscale has its own privacy policy and terms.

Apple handles the iOS installation prompt and validates whether a signed app can install. Deploy Link receives no installation-completion acknowledgement from iOS and does not scan which other apps are installed.

The project contains no advertising or analytics SDK and does not upload diagnostics automatically to its developer. GitHub hosts this website, source code, and public support issues under its privacy statement. This site uses no analytics scripts, cookies, or third-party fonts.

Retention and deletion

Publishing normally keeps the newest five releases per app. Older and expired releases can be removed automatically. Removing a release clears that release’s queue files and transfer log, but the separate device-history file can remain.

The server administrator controls retention of the queue, devices.json, and runtime logs. Stop the server before manually clearing stored history. Removing the whole server data folder removes the queued packages, history, and management token. Deleting the mobile app does not clear server records. The setup guide lists the default paths and shutdown steps.

Contact

Ask a general privacy or support question through GitHub Issues. These are public: do not post tokens, private server addresses, app binaries, provisioning files, device identifiers, or raw logs. Request a private contact route before sharing sensitive detail.
