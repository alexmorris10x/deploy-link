Find the missing step.

The setup guide covers the full path from a signed build to the iOS installation prompt.

The queue will not load

Keep the Mac awake and signed in. Confirm Tailscale is connected on both devices and open the queue’s HTTPS address in Safari on the phone. Use the address printed by your own installer, with no credentials or query string. Check that the server is running and Tailscale rules allow this device to reach it.

If the installer cannot find Python or Tailscale, install the prerequisites and rerun it. If Tailscale reports an existing Serve mapping, preserve that service and choose an appropriate configuration instead of replacing it blindly.

The build says Downloaded, but it did not install

Downloaded means the server completed the file transfer. It does not prove iOS accepted or installed the app. Check the iOS message, signing certificate, profile expiry, required device registration, OS compatibility, and available device storage. Deploy Link cannot repair an invalid signature or bypass provisioning. Build and sign again when necessary, then publish the replacement.

Install is waiting, or another download is busy

Confirm or dismiss the iOS prompt. Deploy Link waits briefly for a transfer to start and avoids starting another build of the same app on the same device while one is downloading. Refresh after the prompt ends. A lost connection can require retrying the download.

A build disappeared

Publishing retains only the newest configured number of releases per app, and expired profiles leave the queue. The administrator can also prune or remove builds. Download history can remain after a release is removed, but the removed package cannot be downloaded again until it is republished.

I cannot delete a queued build

Queue deletion needs the management token for your selected server. The token is optional for listing and downloads. Copy it locally with ota-queue admin-token --copy, then add it in the app’s settings. If the server’s token changes, update the app too. Never put a token in a URL or support issue. Removing a queue entry does not uninstall an app from your devices.

Can I use it without the iOS app?

Yes. The server includes a queue page you can open in Safari over the same private HTTPS address. It hands installation to iOS and has the same signing and provisioning limits. App Store availability for the native client is still being prepared.

Ask for help

Open a support issue

Include the Deploy Link version, macOS/iOS versions, Python version, which step failed, and the error with private details removed. State whether the queue opens in Safari and whether the file transfer completed.

Issues are public. Do not attach tokens, signing files, private builds, device identifiers, private server URLs, or raw logs. Ask for a private contact route if those are needed.
